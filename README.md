# Pràctica PHP UF2 — Versió BASE (sense solucions)

Aquesta és la versió **BASE** per a l'alumnat. Els fitxers d'`exercicis/` contenen l'enunciat,
pistes i espais **TODO**, però no la solució.

## Com iniciar (Codespaces)
- Obri el repo en GitHub Codespaces.
- Executa la tasca **Serve PHP (localhost:8000)** o: `php -S 0.0.0.0:8000 -t .`
- Obri la URL pública i navega per `index.php` (paràmetre `?e=01` .. `?e=12`).

Bona pràctica!
